# Hustlify Post Studio (React SPA)

Студия контент-плана и постов для Telegram-канала **Hustlify**: планирование публикаций, мгновенная подготовка постов с баннерами и согласование.

## Возможности

- **Контент-план**:
  - Календарь постов по дням со статусами («ждёт», «готовлю…», «пост сделан», «ошибка»).
  - Кнопка **«Сделать сейчас» / «Сделать заново»** — моментально генерирует текст поста с хуком и типографикой Telegram HTML, баннер и кнопки.
  - Импорт собственного плана из текста с автоматическим распознаванием дат.
  - Генератор плана по материалам баз на 1–31 день с выбором фокуса.

- **Новый пост**:
  - Выбор темы и тезисов.
  - Прикрепление материалов из баз (каталог, кейсы, вакансии).
  - Настройка баннера (фон, иконка, заголовок, подзаголовок, плашка).
  - Интерактивный предпросмотр баннера в реальном времени.

- **Посты (Очередь и архив)**:
  - Векторные баннеры (SVG) с возможностью скачивания.
  - Быстрый просмотр и правка черновика (Telegram-карточка с разметкой).
  - Блок кнопок «Название - Ссылка» для копирования в один клик.
  - Ревизия поста по текстовым инструкциям («сделай короче», «добавь дедлайн 24 часа»).
  - Публикация и удаление.

- **Настройки**:
  - Часовой пояс и время ежедневного поста.
  - Поддержка премиум-эмодзи.
  - Редактор ссылок для кнопок в формате JSON.
  - Редактор редакционного стиль-промпта.
  - Интеграция с Telegram Bot API (проверка токена и чата).

## Запуск

```bash
npm run dev
```

Приложение запускается на порту 3000 (`http://localhost:3000`).
