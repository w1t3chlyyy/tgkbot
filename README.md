# Hustlify · бот-студия постов (Vercel)

Ты присылаешь боту **контент-план** (текстом или файлом .txt). Каждый день в заданное время (по умолчанию 10:00) бот сам делает пост по плану (текст через **Qwen**, баннер с 3D-объектом, кнопки) и **присылает его тебе на согласование**: опубликовать, поправить текст, сменить баннер, выбрать другое время. Только после твоего «да» пост уходит в канал.

## Как это устроено на Vercel

Vercel не держит постоянных процессов, поэтому:
- Telegram шлёт сообщения боту **вебхуком** на `/api/webhook`;
- «таймером» служит **cron-job.org**: раз в минуту он открывает `/api/cron`, а тот публикует просроченные посты и проверяет, не пора ли готовить ежедневный пост (Vercel Cron на бесплатном Hobby умеет только раз в сутки);
- «память» диалога («жду текст правки») хранится в базе Supabase.

## Развёртывание

1. **Supabase**: SQL Editor → выполни `supabase/schema.sql`. Нужны Project URL и ключ `service_role`.
2. **Telegram**: бот у @BotFather (токен), свой ID у @userinfobot, бот — админ канала с правом публикации.
3. **Qwen**: ключ в Model Studio (Alibaba Cloud); `QWEN_BASE_URL` должен совпадать с регионом ключа.
4. **Vercel**: New Project → импорт репозитория → Environment Variables (см. `.env.example`) → Deploy.
5. **Регистрация вебхука** (один раз): открой в браузере `https://ТВОЙ-ПРОЕКТ.vercel.app/api/setup?secret=ТВОЙ_CRON_SECRET`. Должен прийти JSON с `"ok": true`.
6. **cron-job.org**: новая задача, URL `https://ТВОЙ-ПРОЕКТ.vercel.app/api/cron?secret=ТВОЙ_CRON_SECRET`, расписание «каждую минуту».
7. В Telegram: `/start` → `/channel @канал` → пришли план.

## Использование

- **План**: пришли боту текст вида «30.10 Рулетка / 31.10 Как купить Stars / …» (даты можно не указывать: тогда пункты идут по дням подряд). Бот спросит «это план?», разберёт и сохранит. Новый план заменяет ещё не сделанные пункты на те же даты.
- **Время**: `/dailytime 10:30`; выключить авто-режим: `/daily off`; `/plan` — статусы; `/today` — сделать пост на сегодня прямо сейчас.
- **Согласование** (под каждым постом): Опубликовать сейчас · Другое время · Править текст · Баннер · Другой вариант · Отмена.
- **Отдельный пост**: напиши тему (с новой строки тезисы).
- **Мини-приложение** (`/studio`): очередь с превью, новый пост с материалом из баз, план, настройки.

## Базы сайта, эмодзи, 3D

Как в прежней версии: `DATABASES` в переменных (лучше anon-ключ с read-only доступом; чувствительные таблицы скрыты), `/pack` для премиум-эмодзи (Telegram может не принять их от бота, тогда пост уходит с обычными), 3D-библиотека в `assets/3d/` (перерисовка: `tools/render3d/`).

## Важное про Vercel

- Бесплатный Hobby рассчитан на некоммерческое использование; для коммерческого проекта нужен Pro.
- Лимит времени функции задан 60 с (`vercel.json`): генерация поста с баннером обычно укладывается. Тяжёлую работу cron выполняет через `waitUntil`, поэтому cron-job.org получает ответ сразу.
- Дополнительно, на Vercel Pro, можно вместо cron-job.org завести встроенный cron: `"crons": [{"path": "/api/cron", "schedule": "* * * * *"}]` в `vercel.json` (на Hobby деплой с такой строкой упадёт).

## Запуск на обычном сервере

`npm start` (long polling + таймер внутри процесса) или Docker. Для этого режима вебхук не нужен, cron-job.org тоже.

## Структура

`api/[...all].js` вход Vercel · `src/bot.js` диалог · `src/planner.js` разбор плана и ежедневный пост · `src/scheduler.js` тик cron · `src/miniapp.js` вебхук, cron, API · `src/post.js` Qwen · `src/banner.js` баннеры (resvg) · `src/sources.js` внешние БД · `supabase/schema.sql` · `tests/` — `npm test`.
