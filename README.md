# Hustlify · бот-студия постов

Бот + мини-приложение для Telegram-канала. Ты даёшь тему (текстом боту или через мини-приложение), **Qwen** пишет пост и подбирает баннер, бот рендерит баннер (3D-объекты + Unbounded/Montserrat, палитра ч/б + синий) и **присылает черновик в чат с вопросом «Всё устраивает?»**. После одобрения пост выходит в канал сразу или по таймеру.

## Как это работает

1. Пишешь боту: `Рулетка промокодов` (+ тезисы с новой строки), либо открываешь мини-приложение и выбираешь материал из баз.
2. Бот присылает точную копию будущего поста (баннер, текст, кнопки) и панель:
   **Опубликовать сейчас · Другое время · Править текст · Баннер · Другой вариант · Отмена**
3. «Править текст»: пишешь словами («короче», «добавь про 24 часа», «баннер тёмный»), Qwen правит, бот присылает новый вариант.
4. «Баннер»: меняешь макет (светлый/тёмный), 3D-объект (звезда/монета/куб/сфера), надпись на ленте, заголовок, плашку, ссылку.
5. «Другое время»: пресеты или текстом: `завтра 18:30`, `30.10 12:00`, `2026-11-02 09:15`.
6. Планировщик внутри сервиса публикует по времени и пишет тебе, когда готово.

**Мини-приложение:** очередь с превью баннеров · новый пост с выбором материала из баз · контент-план (Qwen составляет план по реальным данным баз, «Сделать пост» ставит время по плану) · настройки (канал, часовой пояс, пак эмодзи, ссылки, стиль-промпт).

## Запуск

Нужен хостинг, где процесс работает постоянно (VPS, Railway, Render, Fly; **не** serverless/Vercel: нужны таймер и long polling) и HTTPS-адрес для мини-приложения.

```bash
cp .env.example .env      # заполни
# Supabase → SQL Editor → выполни supabase/schema.sql (своя база бота)
npm install
npm start
```
Или Docker: `docker build -t postbot . && docker run --env-file .env -p 3000:3000 postbot`.
**Запускай один экземпляр**, иначе два polling-процесса конфликтуют.

Шаги в Telegram:
1. @BotFather → создать бота → токен в `BOT_TOKEN`. Свой Telegram ID (узнать у @userinfobot) → `ADMIN_IDS`.
2. Добавь бота **админом канала** с правом «Публикация сообщений», затем в чате `/channel @твой_канал`.
3. `PUBLIC_URL` = https-адрес сервиса; команда `/studio` откроет мини-приложение (кнопка «Студия» появится и в меню бота).

## Подключение баз сайта

`DATABASES` в `.env` — массив баз (каталог, кейсы, партнёры, проекты, портфолио; каждая может быть отдельным Supabase-проектом). Для каждой:
- без `tables` бот сам находит таблицы и **скрывает чувствительные** (orders, promocodes, requisites, users, payment, employees, assignments, businesses…);
- с `tables` — только то, что перечислишь; можно указать поле-заголовок (`"products":{"label":"name"}`).

⚠️ Безопасность: содержимое выбранных строк уходит в Qwen. Используй **anon-ключ с read-only политиками** (или отдельную view с публичными полями), а не `service_role`. Поля вроде email/phone/token/key бот отбрасывает автоматически, но не полагайся только на это. Структуру твоих таблиц я не видел, поэтому названия таблиц и колонок сверь по факту.

Если стиль-промпт уже лежит в твоей БД, задай `STYLE_PROMPT_SOURCE` (пример в `.env.example`). Иначе: `/prompt` или «Настройки» в мини-приложении.

## Премиум-эмодзи

`/pack https://t.me/addemoji/ИмяПака`: бот запоминает все эмодзи пака. Qwen пишет пост обычными эмодзи **из твоего пака** (список ему передаётся), а при отправке они заменяются на премиум по совпадению символа. Включить/выключить: `/emoji on|off`.

⚠️ Ограничение Telegram: по документации Bot API премиум-эмодзи в сообщениях бота принимаются только если у бота куплены дополнительные юзернеймы на Fragment (проверь актуальное условие в документации). Если Telegram их отклонит, бот **автоматически отправит пост с обычными эмодзи** и ничего не сломается. Альтернатива: публиковать через user-аккаунт с Premium (MTProto), это отдельная доработка. Премиум-эмодзи внутри текста кнопок в этой версии не поддерживаются.

## 3D-объекты

Готовая библиотека: `assets/3d/` — 4 объекта × 6 надписей на ленте (скидка, конкурс, новинка, кейсы, вакансия, hustlify). Перерисовать или добавить:
```bash
cd tools/render3d && npm i three@0.160.0 && cd ../..
pip install playwright pillow && playwright install chromium
python3 tools/render3d/render_all.py            # всё;  или:  ... star skidka
```
Свои 3D-PNG (прозрачный фон, квадрат) кладутся как `assets/3d/<объект>_<слово>.png`; новые объекты и слова добавь в `OBJECTS`/`WORDS` в `src/prompts.js`. Логотип сейчас текстовый (`HUSTLIFY`), замена: функция `logo()` в `src/banner.js`.

## Структура

`src/bot.js` диалог и согласование · `src/draft.js` карточка черновика · `src/post.js` Qwen (пост, правка, план) · `src/banner.js` рендер баннеров (resvg, без браузера) · `src/sources.js` внешние БД · `src/miniapp.js` API мини-приложения (проверка подписи initData, только `ADMIN_IDS`) · `src/scheduler.js` таймер · `supabase/schema.sql` · `tests/`: `npm test` прогоняет весь поток на моках.
